importance_pageRank.py (what it does)

This version builds an internal graph from the paper structure:
paper -> section/subsection -> paragraph -> citation leaf (if citations exist).
If a paragraph has no citations, that paragraph is a leaf.

Each node has two channels:
- Technical channel (T)
- Citation channel (C)

For each paragraph p, the model gives:
- local_total S(p) in [0,1]
- t_raw(p) >= 0
- c_raw(p) >= 0

Then we split local_total using normalized raw strengths:
- w_t = t_raw / (t_raw + c_raw)
- w_c = c_raw / (t_raw + c_raw)
- local_technical T(p) = S(p) * w_t
- local_citation C(p) = S(p) * w_c

So T(p) + C(p) = S(p).
If paragraph p has no citation mentions, we force C(p)=0 and T(p)=S(p).

Propagation equations (on all graph nodes u):
- TR_{t+1}(u) = (1-alpha)*T(u) + alpha*sum_{v->u} TR_t(v)/out_deg(v)
- CR_{t+1}(u) = (1-beta)*C(u) + beta*sum_{v->u} CR_t(v)/out_deg(v)

Edge meaning and flow:
- Edge v -> u means node v sends flow to node u.
- v splits its current propagated score equally across its outgoing edges.
- Nodes can get non-zero rank from incoming flow even when local channel value is small.

Final paragraph score:
- combined_score(p) = lambda*technical_rank(p) + (1-lambda)*citation_rank(p)

Difference from importance_score.py

importance_score.py:
- Pairwise/all-together LLM scoring over the hierarchy.
- Citation scores come from splitting paragraph scores over mentions.
- No graph propagation.

importance_pageRank.py:
- Explicit technical and citation channels.
- Decomposes local_total with normalized (t_raw, c_raw).
- Runs graph propagation (TR/CR) over hierarchy nodes.
- Outputs section/citation scores that include structural flow effects.
