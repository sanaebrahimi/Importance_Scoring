PageRank scoring guide (short version)

This run uses two local paragraph channels:
- T(p): technical contribution from paragraph text itself.
- C(p): citation-added contribution in that paragraph.

How local paragraph scores are built
- The model gives a technical score T(p) and an overall local score S_local(p).
- Citation part is the difference:
  C(p) = max(0, S_local(p) - T(p))
- If a paragraph has no citation mentions, C(p)=0.
- local_total = local_technical + local_citation

Internal graph used for propagation
- Nodes are built from the paper hierarchy:
  paper -> section/subsection/... -> paragraph -> citation leaves
- If a paragraph has no citations, that paragraph is a leaf.

Propagation equations (applied to every node u)
- TR_{t+1}(u) = (1-alpha)*T(u) + alpha*sum_{v->u} TR_t(v)/out_deg(v)
- CR_{t+1}(u) = (1-beta)*C(u) + beta*sum_{v->u} CR_t(v)/out_deg(v)

Final paragraph score
- combined_score(p) = lambda*technical_rank(p) + (1-lambda)*citation_rank(p)

What each output file contains

run_pagerank_paragraph_scores.json
- local_total, local_technical, local_citation
- technical_rank, citation_rank (from graph propagation at paragraph node)
- combined_score
- normalized_combined_score (normalized so all paragraph combined scores sum to 1)

run_pagerank_section_scores.json
- Hierarchical section tree
- score is normalized contribution
- top-level section scores sum to 1
- each parent score equals sum of children scores

run_pagerank_citation_scores.json
- Citation-level aggregation from citation leaf nodes
- technical_rank and citation_rank are summed over all leaf occurrences of the citation
- combined_score uses the same lambda blend

run_pagerank_paper_scores.json
- local paper values before propagation
- propagated paper-node technical_rank and citation_rank
- decomposition into kept_local and inherited_flow
- graph details (nodes, edges, node metadata)
